## 已讨论及表现

使用的模拟输入：

```python
import numpy as np

x = np.arange(24).reshape(2, 4, 3)
```

三个轴依次表示文本条数、每条文本的 token 数、每个 token 的向量分量。

- 学员能解释 `x[0]` 和 `x[:, -1, :]` 的选择含义。
- 已讲解 `mean(axis=1)` 对各 token 向量的相同分量求平均。
- 学员能判断 `mean(axis=2)` 的输出形状为 `(2, 4)`；已纠正为“每个 token 内部的分量求平均”。
- 已讲解默认求平均会去掉对应的轴，而 `keepdims=True` 将对应轴保留为长度 1。
- 学员曾将 `keepdims=True` 理解为添加数值 1，随后又混淆 `(2, 1, 3)` 与 `(2, 3, 1)` 的括号结构；已给出纠正。
- 最近一次检查：输入形状 `(8, 16, 64)`，学员正确回答 `mean(axis=1, keepdims=True)` 的形状为 `(8, 1, 64)`。
- 已讲解矩阵乘法规则 `(m, n) @ (n, p) -> (m, p)`。
- 学员正确回答 `(2, 4, 3) @ (3, 5)` 的输出形状为 `(2, 4, 5)`。
