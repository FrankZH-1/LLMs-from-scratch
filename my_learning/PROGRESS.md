## 已完成：自动求导与平方误差入门

先讲解了以下最简单的标量例子，学员正确判断将 `w` 改为 5 时，输出为 10、梯度仍为 2：

```python
import torch

x = torch.tensor(2.0)
w = torch.tensor(3.0, requires_grad=True)
y = w * x

y.backward()

print("输出：", y.item())
print("梯度：", w.grad)
```

讲解：`requires_grad=True` 让 PyTorch 跟踪与权重有关的运算；`y.backward()` 计算输出对权重的导数并累积到 `w.grad`。梯度描述固定输入时输出对权重的变化率，区别于输出本身。该例计算一次梯度，不会更新权重。

随后引入 `loss = (y - 10) ** 2`，将反向传播改为 `loss.backward()`。

- 学员报告 `w=3` 时输出为 6、损失为 16、损失对权重的梯度为 -16，均正确。
- 已讲解链式法则：`d(loss)/dw = 2(y-10) * x`。
- 学员将 `w=6` 时的梯度答为 -8，已纠正为 +8，并解释在输入为正的本例中，预测超过目标后继续增大权重会增大损失。
- 学员正确回答 `w=5` 时预测为 10、损失为 0、梯度为 0。
- 导师已查看 `exercise/l2.py`，当前代码使用 `w=6.0`，计算平方误差并调用 `loss.backward()`，尚未编写权重更新。
