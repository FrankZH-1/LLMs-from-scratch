### 练习 02：手写训练循环与梯度清零

建议文件：`02_training_loop.py`。

目标：把一次权重更新扩展为可重复运行的训练过程，理解梯度清零及学习率的作用。

任务：

1. 从练习 01 的末尾开始，解释梯度约 9.6 的来源；在下一次反向传播前清除旧梯度，验证新梯度约 1.6。
2. 使用输入 `x=2`、目标值 10、初始权重 6，手写 20 次“清除梯度 → 前向计算 → 计算损失 → 反向传播 → 更新权重”的循环。
3. 分别用学习率 0.01、0.1、0.3 运行，每次重新初始化权重。记录每一步的权重和损失，比较三种设置。

检查点：分清当前权重下的梯度与累积梯度；更新后重新计算才得到新预测；记录的损失与权重必须属于同一个计算时点；能够解释不同学习率的表现。

提交：代码、三组初始及最终结果、关于学习率和梯度清零的简短解释。手写更新完成后，再讨论为什么优化器能够替代这些操作。

### 练习 03：用模型层和优化器拟合直线

建议文件：`03_linear_regression.py`。

目标：从一个手工权重过渡到带权重和偏置的 `torch.nn.Linear`，使用 `MSELoss` 与 `torch.optim.SGD`。

任务：

1. 构造 5 个输入 `[-2, -1, 0, 1, 2]`，目标关系为 `y=3x+2`。输入和目标都整理成 `(5, 1)` 的浮点张量。
2. 创建 `nn.Linear(1, 1)`，固定随机种子以方便复现。用均方误差、学习率 0.1、SGD 训练约 100 步；使用优化器清除梯度和更新参数。
3. 比较训练前后的损失，查看学到的权重和偏置，并预测新输入 `x=3` 的输出。

检查点：能够解释输入和输出形状、权重与偏置的作用，以及 `zero_grad()`、`backward()`、`step()` 的执行顺序。

提交：代码、初始及最终损失、学到的参数、新输入的预测，以及手写更新与优化器的对应关系。

### 练习 04：小批量训练与评估

建议文件：`04_minibatch_training.py`。

目标：用 `TensorDataset` 和 `DataLoader` 组织多条样本，区分一个 batch、一个训练步骤和一个 epoch。

任务：

1. 固定随机种子，生成 64 个位于 `[-2, 2]` 的输入，目标为 `y=3x+2`，形状均为 `(64, 1)`。将前 48 条用作训练，后 16 条用作验证。
2. 构造训练用 `TensorDataset` 和 `DataLoader`，设置 `batch_size=8`、`shuffle=True`，打印第一个 batch 的输入及目标形状。
3. 使用新的 `nn.Linear(1, 1)`、SGD 和均方误差训练约 30 个 epoch，学习率先用 0.05。每个 batch 都清除梯度、前向计算、反向传播并更新参数。
4. 每个 epoch 结束后，对完整训练集和验证集重新计算损失；评估使用 `model.eval()` 与 `torch.no_grad()`，下一轮训练前调用 `model.train()`。

检查点：能说明每个 epoch 有多少次权重更新；区分训练与评估；能对比初始及最终验证损失。此处线性模型的 `train()` / `eval()` 不改变数值行为，提前建立后续使用其他层时需要的流程习惯。

提交：代码、batch 形状、每个 epoch 的训练与验证损失、最终参数，以及 batch、step、epoch 三者的关系。
